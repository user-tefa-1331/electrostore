# ElectroStore – Tienda Virtual

## Descripción del proyecto

ElectroStore es una tienda virtual de productos electrónicos desarrollada como parte de la práctica de Desarrollo de Software Colaborativo de SENATI.

El proyecto permite visualizar un catálogo de productos electrónicos, consultar sus precios y agregar productos a un carrito de compras.

## Objetivo

Aplicar los conocimientos de desarrollo web y control de versiones mediante Git y GitHub, utilizando ramas para organizar el desarrollo de funcionalidades.

## Tecnologías utilizadas

- HTML5: estructura de la página web.
- CSS3: diseño y presentación visual.
- JavaScript: funcionamiento del carrito de compras.
- Git: control de versiones.
- GitHub: almacenamiento y gestión del repositorio.

## Funcionalidades

- Visualización de productos electrónicos.
- Catálogo con nombres, descripciones y precios.
- Agregar productos al carrito.
- Eliminar productos del carrito.
- Calcular el total de la compra.
- Vaciar el carrito de compras.

## Organización de ramas

- `main`: versión principal del proyecto.
- `develop`: integración de funcionalidades.
- `feature/catalogo-productos`: desarrollo del catálogo.
- `feature/carrito-compras`: implementación del carrito.

## Flujo de trabajo

1. Inicialización del repositorio Git.
2. Creación del primer commit.
3. Creación de la rama `develop`.
4. Desarrollo del catálogo en una rama independiente.
5. Integración del catálogo mediante Git merge.
6. Desarrollo del carrito de compras.
7. Integración de las funcionalidades en `develop`.
8. Publicación de la versión final en `main`.
9. Creación de la etiqueta `v1.0.0`.

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador.
